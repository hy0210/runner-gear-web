# 需求與評分標準摘要

需求來源：<https://polar-client-338.notion.site/2026-3f96e9dba9138040a565c63bb58e84bb>
本摘要整理自專案的開發計畫（v6）；若與需求原文有出入，以原文為準。

- 主題：跑步裝備店（前後端整合電商平台）
- 繳交期限：2026/11/24（二）23:59；線上需正常運作至 2026/12/04
- 及格標準：總分 ≥ 70，後端 ≥ 24/40，前端 ≥ 24/40

## 不予評分的條件（缺一即不予評分）
- 前端網址可公開連線
- 後端 API Base URL 可用 Postman 呼叫
- 兩個 Repo 皆為 public
- API 文件可公開閱讀

## 必做功能（後端）
- 會員：註冊、登入（密碼雜湊、JWT）
- 商品：列表（分頁、分類篩選、關鍵字搜尋）、單一商品；管理員可新增、編輯、刪除
- 購物車：查看、加入、調整數量、移除
  - 邊界情況：重複加入同一商品要累加、商品不存在回 404、數量非正整數回 400、未登入回 401、不可操作他人的購物車
- 權限：一般會員呼叫管理員 API 得 403；註冊無法取得管理員身分

## 不做
訂單、金流、後台管理頁、商品詳情頁、忘記密碼、refresh token。
